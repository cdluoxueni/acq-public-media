隐私政策 / Privacy policy

生效日期 / Effective date：2026-11-04

本政策适用于「北美餐馆老板算账 发布工具」。这是账号运营者自用的本地内容发布工具，只访问运营者本人明确授权的 YouTube 频道数据，不向公众提供登录或账号接入。

This policy applies to “北美餐馆老板算账 发布工具”, a local content publishing tool for the account operator’s own use. It accesses only YouTube channel data explicitly authorized by that operator and does not offer public sign-in or account connections.

1. Google 数据与用途 / Google data & purposes

本工具通过 Google OAuth 请求以下权限，并仅用于本人频道的内容发布与统计查看：

The tool requests the following Google OAuth permissions solely to publish content and view statistics for the operator’s own channel:

  • https://www.googleapis.com/auth/youtube.upload
    上传运营者自己制作的短视频及相关标题、说明等发布信息到自己的 YouTube 频道。
    Upload the operator’s own short videos and associated publishing information, such as titles and descriptions, to their own YouTube channel.
  • https://www.googleapis.com/auth/youtube.readonly
    读取本人授权的频道与视频信息、发布状态和可用统计数据，用于确认频道、核对发布结果及查看内容表现。
    Read the authorized operator’s channel and video information, publishing status, and available statistics to identify the channel, check uploads, and review content performance.
  • https://www.googleapis.com/auth/yt-analytics.readonly
    读取本人频道的非收入类 YouTube Analytics 报告，例如观看次数、观看时长和互动数据，用于评估自己的内容表现。
    Read non-monetary YouTube Analytics reports for the operator’s channel, such as views, watch time, and engagement, to evaluate their own content.

2. 存储与保护 / Storage & protection

Google OAuth 访问令牌与刷新令牌仅保存在运营者本机，不放入本公开网站或公开代码仓库。本工具保存的频道信息、发布记录和统计数据也保存在运营者本机，仅用于上述功能；与 Google API 的通信通过 HTTPS 进行。

Google OAuth access and refresh tokens are stored only on the operator’s local computer, never on this public website or in its public repository. Channel information, publishing records, and statistics retained by the tool are also stored locally and used only for the purposes above. Communication with Google APIs uses HTTPS.

3. 共享与广告 / Sharing & advertising

我们不出售、不向第三方共享通过 Google API 获得的数据，不将其用于广告、定向营销或数据经纪业务。仅为完成本人授权的视频上传与数据查询而与 Google/YouTube 交换所需数据。上传的视频及其信息按运营者在 YouTube 选择的可见性设置展示。

We do not sell or share data obtained through Google APIs with third parties, or use it for advertising, targeted marketing, or data brokerage. Required data is exchanged with Google/YouTube only to carry out the operator’s authorized uploads and queries. Uploaded videos and their information are displayed according to the visibility settings selected by the operator on YouTube.

4. 保留、撤销与删除 / Retention, revocation & deletion

令牌仅在本人持续授权并使用本工具期间保留；本地频道数据与统计记录仅在上述发布和统计用途需要期间保留。运营者停止使用或撤销授权后，应删除本机令牌文件、缓存、相关频道数据、统计记录及其备份。

Tokens are retained only while the operator continues to authorize and use the tool. Local channel data and statistics are retained only as needed for the publishing and analytics purposes above. When use ends or access is revoked, the operator should delete local token files, caches, related channel data, statistics, and their backups.

可随时在 Google 账号的第三方应用权限页面移除本工具的访问权限，阻止后续访问。撤销授权不会自动删除本地副本，需按上述方式手动清除；也不会自动删除已上传的 YouTube 视频，视频可在 YouTube Studio 中单独管理或删除。

Access can be revoked at any time through Google Account third-party app permissions to stop further access. Revocation does not automatically erase local copies; delete them manually as described above. It also does not delete previously uploaded YouTube videos, which can be managed or deleted separately in YouTube Studio.

5. Google 数据政策 / Google data policy

本工具对从 Google API 收到的信息的使用及向任何其他应用的传输，将遵守 Google API Services User Data Policy，包括其中的 Limited Use（受限使用）要求。

The tool’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

6. 本网站 / This website

这些公开说明页面不收集 Google 授权令牌，不提供登录，不使用外部脚本、广告、分析工具或追踪 Cookie。页面由 GitHub Pages 托管；托管服务可能处理访问所需的技术日志，详见 GitHub 隐私声明。

These public information pages do not collect Google authorization tokens, offer sign-in, or use external scripts, ads, analytics tools, or tracking cookies. They are hosted on GitHub Pages; the hosting provider may process technical access logs as described in the GitHub Privacy Statement.

7. 联系与更新 / Contact & updates

通过 YouTube 频道或 Facebook 主页「北美餐馆老板算账」私信联系。政策更新将在本页公布并更新生效日期；如数据用途发生变化，将在新的访问或使用前取得相应授权。

Contact us through the YouTube channel or by private message to the Facebook page “北美餐馆老板算账”. Policy updates will be posted here with an updated effective date. Any change in data use will require appropriate authorization before new access or use begins.
